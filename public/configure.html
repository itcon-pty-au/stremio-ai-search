Stremio AI Search

Choose any OpenAI-compatible endpoint.
Works with any OpenAI-compatible provider. For OpenRouter, use an API key from OpenRouter.
Use a model name supported by your provider (OpenRouter uses names like openai/gpt-4o-mini).

OpenRouter tip: append :online to the model name (e.g. google/gemini-2.5-flash:online) to let the model search the web before answering. This gives noticeably better results for "latest" / "new" queries, which otherwise return titles from the model's training cutoff. OpenRouter charges a small fee per search.
Using OpenRouter? This must be https://openrouter.ai/api/v1 — leaving it blank sends your key to OpenAI and fails with "Incorrect API key provided". It is filled in for you when your key starts with sk-or-v1-.
Other examples: https://api.openai.com, https://api.z.ai/api/paas/v4
Optional JSON headers to send with requests (some providers like OpenRouter recommend HTTP-Referer and X-Title). Don’t include Authorization.

Only tick this if you watch in a browser at web.stremio.com. Leave it off for the desktop, Android or TV apps — they follow stremio:// links, and sending them a web link opens a browser tab where your addons are not installed.
If disabled, the AI recommendation catalogs will not appear on your Stremio homepage.
Enter a comma-separated list of catalogs in the format Title:Query. Each entry will create a new catalog on your homepage. e.g. `Mystery:recommend mystery thrillers,Sports:recommend sports movies` gives three catalogs titled "Mystery - Movie", "Mystery - Series", and "Sports - Movie". To show only movies for a query, add the word "movies" to it (e.g., `Thriller:thriller movies`). This prevents a series catalog from appearing for that query. For new content, use 'New' keyword (e.g., `New Releases:new action movies`).
